# Employee Data Validation Rules

## 1. Employee ID

- Employee ID is required.
- Employee ID must be unique.
- Employee ID must follow the defined format.

## 2. Email Address

- Email Address is required.
- Email Address must follow a valid email format.

## 3. Required Fields

- Required employee fields must not be empty.
- Employee records must contain the information needed for record identification.

## 4. Contract Dates

- Contract Start Date must be provided when applicable.
- Contract End Date must not be earlier than Contract Start Date.

## 5. Validation Outcomes

- Valid data should pass validation.
- Invalid data should be rejected.
- The system should display a clear error message when validation fails.
