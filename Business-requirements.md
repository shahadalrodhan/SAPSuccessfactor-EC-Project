# Business Requirements

## 1. Business Problem
Employee information is stored in different places, making it difficult to access and manage employee records efficiently.

## 2. Business Goal
To centralize employee information in one system, improve data accessibility, reduce the time needed to manage employee records and simplify employee leave management.

## 3. Project Scope
- Validate employee information
- Provide easy access to employee records
- Manage employee leave requests and balances

  ## 4. Business Requirements
- **BR01:** The system must provide access to employee data using the Employee ID.
- **BR02:** The system must validate employee data.
- **BR03:** The system must support employee leave management.
- **BR04:** The system must allow users to submit leave requests using the Employee ID, start date and end date.
