# Business Requirements

## 1. Business Problem

Employee information is stored in different places, making it difficult to access and manage employee records efficiently. Inconsistent or invalid data can also affect data quality.

## 2. Business Goal

To centralize employee information, improve access to employee records, reduce the time required to manage employee data, and improve data accuracy.

## 3. Project Scope

- Access employee records using the Employee ID.
- Validate employee information.
- Maintain employee personal and employment information.
- Validate contract start and end dates.

## 4. Business Requirements

- **BR01:** The system must allow users to access employee records using the Employee ID.
- **BR02:** The system must validate employee data to ensure accuracy and completeness.
- **BR03:** The system must reject contract end dates that are earlier than contract start dates.
